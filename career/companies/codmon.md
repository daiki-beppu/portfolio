# 株式会社コドモン

## なぜ気になったか

**プロダクトへの純粋な共感。** SmartHR とは対照的に、プロダクトそのものに惹かれた。

### プロダクトへの共感

保育・子供という**ドメインへの共感**と、それが解決する**社会課題の明確さ**が惹かれたポイント。個人的な体験（子供がいる等）からではなく、プロダクトの価値に純粋に共感している。

SmartHR（人事労務 SaaS）にはプロダクトとしてピンとこなかったが、コドモンには惹かれる。その違いは**社会課題の明確さ**。保育の課題は誰でもイメージしやすく、解決する価値が直感的にわかる。

### XP 開発文化への強い共感

スライド資料から判明した開発文化が非常に魅力的:

- **毎日ペアプロ** — 一人で FE を担当してきた現職との最大の違い。期待が大きい
- **TDD 実践** — 自分も AI 駆動 TDD を実践しており、親和性が高い
- **XP の価値観**: コミュニケーション、シンプルさ、フィードバック、勇気、リスペクト
- **週1レトロスペクティブ**
- **半年に1度の360度フィードバック**
- **月1 LT 大会、定期勉強会**
- **テックチャレンジ補助（年間6万円）**

## 自分の軸との接点

### 環境面

- シニアエンジニアから学べるか: **毎日のペアプロで直接学べる。** 一人で判断してきた現職とは根本的に違う。FB 文化の不在を最もダイレクトに埋める環境
- 技術基準の高さ: XP ベース（TDD + ペアプロ + 受け入れテスト）で品質を文化として担保。コードレビュー文化あり
- リモート / 柔軟な働き方: フルリモート可、フレックスタイム制 → 条件を満たす

### プロダクト面

- 情熱を持てるか: **YES。** SmartHR との最大の違い。社会課題の明確さに惹かれ、高い熱量で働ける自信がある。「興味のあるプロダクトなので自分でもいろんな FB を見つけられると思う」
- 長期的に育てられるか: 自社プロダクト。技術負債の解消を継続中（2021年〜）で、長期的に貢献する余地がある

### 成長面

- テックリードとしての成長: 明示的なリーダーポジションではないが、XP 環境でのチーム開発経験は将来のリード力に直結する
- AI 駆動開発との親和性: **自分の強みを活かせるポイント。** 現在 GitHub Copilot を使用。AI 駆動 TDD の知見を持ち込み、技術負債の解消を加速させる提案ができる

### モチベーション源泉との対応

1. **裁量と影響力** → XP のフラットなチーム体制。AI 駆動開発の提案で影響力を発揮できる可能性
2. **FB と成長実感** → **毎日ペアプロ + 360度FB で最も充実。** SmartHR より確実に FB を得られる環境
3. **技術的チャレンジ** → 技術負債の解消、Vue.js/Nuxt 3 への挑戦、XP プラクティスの習得

## コドモンでの理想像（具体的に4つ浮かんでいる）

1. **AI 駆動の提案で技術負債の解消を加速する** — 自分の AI × TDD の知見をチームに持ち込む
2. **ペアプロで質の高い FB をもらいながら成長している** — 現職で最も不足していたもの
3. **興味のあるプロダクトなので高い熱量で毎日仕事に励んでいる** — プロダクト共感がモチベーションに直結
4. **興味のあるプロダクトなので自分でもいろんな FB を見つけられる** — ユーザー視点を持てる

※ SmartHR の理想像は「チームを牽引するリーダー」という抽象的な1つだけだったのに対し、コドモンは4つの具体的なシーンが浮かんでいる

## 総合評価

**転職の軸（FB 文化・成長環境・プロダクト共感）との適合度はコドモンの方が高い。** 毎日ペアプロ + TDD + 360度FB は、現職で最も不足している「フィードバック文化」を最もダイレクトに埋める。プロダクトへの共感も SmartHR より明確で、理想像も具体的。

一方で、SmartHR に心が傾いているのは**規模・知名度（キャリア戦略 + 大規模組織での挑戦）**と**バリューへの深い共感（「光」= 自分の生き方）**による。

**問いかけ**: 「自分の転職の軸に最も合う環境」と「キャリア戦略としてのブランド力」のどちらを優先するか。この問いに向き合うことが、最終的な判断の鍵になる。
