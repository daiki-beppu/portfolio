# 転職理由

## 前提

現職に対する不満から転職を考えているわけではない。未経験の自分に FE を一人で任せてくれたこと、技術選定やツール導入の提案を自由にさせてくれたこと、短期間で3つのプロジェクトを並行して経験できたことには感謝している。

## なぜ転職を考えているか

現職で得られた「幅広い経験」と「自由度」に感謝しつつも、次のステップとして以下を求めている:

### 1. シニアエンジニアから学べる環境

現職では FE をほぼ一人で担当しており、技術的なメンターやレビューで指摘をくれるシニアエンジニアがいない。独学で成長してきた分、自分の設計や判断が正しいのか客観的にフィードバックを受ける機会が少ない。技術的に尊敬できるエンジニアがいる環境で、レビューや議論を通じてさらに成長したい。

### 2. 高い技術基準がある組織

コード品質や設計に対する高い基準が当たり前の組織に身を置きたい。自分自身が DX 改善やレビュー文化を推進してきた経験があるからこそ、それが文化として根付いている環境で自分の基準をさらに引き上げたい。

### 3. 情熱を持てるプロダクトへの関与

受託案件を並行して進める中で、一つのプロダクトを長期的に育てたいという気持ちが強くなった。自分が愛着を持てるプロダクトに対して、技術的な意思決定がプロダクトに反映される実感を持ちながら働きたい。

### 4. 総合的な評価

報酬、技術的な機会、役割・ポジションを含め、自分の成果と成長に見合った評価をしてくれる環境で貢献したい。

## まとめ

現職への感謝を持ちつつ、「自分をより高く評価してくれる環境で、より大きな貢献をしたい」というのが転職の動機。今の自分に足りないもの（シニアからのフィードバック、高い技術基準）を得られる環境で、テックリードとして次のステージに進みたい。
