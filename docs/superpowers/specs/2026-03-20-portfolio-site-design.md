# ポートフォリオサイト デザインスペック

## 概要

転職活動と個人プロジェクトのショーケースを兼ねたポートフォリオサイト。craftz.dog のようなミニマル・ダークなトーンで、シングルページ構成。日英両対応。

## 要件

| 項目           | 決定事項                                             |
| -------------- | ---------------------------------------------------- |
| 目的           | 転職活動 + 作品ショーケース                          |
| ブログ         | なし（外部サービスで対応）                           |
| 言語           | 日英両対応（`react-i18next` + JSON 翻訳ファイル）    |
| コンテンツ管理 | コード内で管理（`docs/` の Markdown はあくまで素材） |
| 更新頻度       | たまに（プロジェクト完成時や転職活動タイミング）     |
| ドメイン       | Cloudflare Pages デフォルト（`xxx.pages.dev`）       |

## 技術スタック

| カテゴリ       | 技術                                               |
| -------------- | -------------------------------------------------- |
| ツールチェーン | Vite+（Vite / Vitest / Oxlint / Oxfmt を統合管理） |
| フレームワーク | React                                              |
| 言語           | TypeScript                                         |
| スタイリング   | Tailwind CSS                                       |
| i18n           | react-i18next                                      |
| アニメーション | framer-motion（控えめなスクロールアニメーション）  |
| デプロイ       | Cloudflare Pages（無料枠）                         |

Vite+ により `vp dev` / `vp build` / `vp check` / `vp test` で開発・ビルド・リント・フォーマット・テストを一元管理。ESLint / Prettier の個別設定は不要。

## デザイン方針

- **トーン**: ミニマル・ダーク（craftz.dog 参考）
- **配色**: ダークモードベース。モノトーン（`#0a0a0a` 背景、`#fafafa` テキスト）+ アクセントカラー（実装時に決定。候補: teal `#14b8a6` や blue `#3b82f6` 等、リンクやホバー状態に使用）
- **タイポグラフィ**: system-ui ベース、letter-spacing を活かしたセクションラベル
- **アニメーション**: 控えめ（セクションのフェードイン、ホバーエフェクト程度）。3D モデルなし
- **レスポンシブ**: モバイルファースト

## ページ構成

シングルページ。5セクションを縦に配置。

### 1. Hero

- **レイアウト**: 左寄せ配置
- **内容**:
  - 肩書きラベル（`FRONTEND ENGINEER`、uppercase、letter-spacing）
  - 名前（大きめフォント、太字）
  - キャッチコピー（1〜2行、色は抑えめ）
  - ソーシャルリンクアイコン（GitHub / X / メール）— 丸枠のアイコンボタンとして横並び
- **ナビゲーション**: 上部に固定ヘッダー。ロゴ（左）+ セクションリンク（右）+ 言語切替ボタン（EN/JA）
- **レスポンシブ**: モバイルではハンバーガーメニュー

### 2. About

- **レイアウト**: ストーリー型
- **内容**:
  - セクションラベル（`ABOUT`）
  - 2〜3段落のテキスト。鳶職→エンジニアのストーリー、強み、やりがいを簡潔に
  - 最大幅を制限（`max-width: 520px` 程度）して読みやすさを確保
- **トーン**: 読ませるデザイン。テキスト色は `#ccc` 程度で目に優しく

### 3. Projects

- **レイアウト**: カードグリッド（2列、モバイルで1列）
- **各カードの構成**:
  - サムネイル領域（グラデーション背景 + アイコンまたはスクリーンショット）
  - プロジェクト名（太字）
  - 1行説明文
  - 技術タグ（小さめのピル型バッジ）
- **対象プロジェクト**:
  1. YouTube チャンネル自動運用システム — Python / AI API
  2. specv — TypeScript / React / Hono
  3. dotfiles — Nix
  4. リベ大フェス2025 — イベント
- **リンク先**: 各カードから GitHub リポジトリへリンク。specv は npm ページ、リベ大フェスは LP サイトへもリンク可能
- **サムネイル**: 初期はグラデーション背景 + 絵文字アイコンで実装。スクリーンショットは後から差し替え可能
- **インタラクション**: ホバーで軽くリフトアップ or ボーダー色変化

### 4. Career

- **レイアウト**: タイムライン型（縦線 + ドット）
- **粒度**: プロジェクト単位。すべて同一企業（BtoB SaaS スタートアップ、2024.10〜現在）内の案件だが、タイムラインではプロジェクトごとに分けて表示する。企業名は冒頭に1行記載。
- **構成**（上が新しい）:
  1. PJ3: 業務管理 Web アプリ（ゼロベース新規構築）— 2025.10〜現在
  2. PJ2: 業務管理マルチアプリ（3アプリ統合）— 2025.08〜現在
  3. PJ1: BtoB 業務管理 Web アプリ（jQuery → Next.js）— 2025.02〜現在
  4. 鳶職 → 独学でエンジニア転職 — 〜2024（前職。ここだけ異なるフェーズとして視覚的に区別）
- **各項目の内容**:
  - 期間ラベル
  - プロジェクト名（太字）
  - 1〜2行の概要
  - 技術タグ（最新のプロジェクトのみ表示）
- **ビジュアル**: 最新のドットは白塗り、過去は灰色、鳶職は中空の丸で差別化

### 5. Skills

- **レイアウト**: タグクラウド型（カテゴリ別）
- **カテゴリと内容**:
  - **Frontend**: TypeScript / React / Next.js / Tailwind CSS / shadcn/ui / TanStack Query
  - **Testing**: Vitest / Playwright
  - **Infra / Tools**: Vercel / GitHub Actions / Claude Code / Nix
  - **Sub**: Python / Shell Script / SQL（スタイルを抑えめにしてメインとの差を出す）
- **タグスタイル**: `background: #1a1a1a` + `border: 1px solid #333` のピル型。Sub カテゴリはボーダーとテキスト色をさらに暗くして視覚的に差別化

## ナビゲーション

- 固定ヘッダー（スクロール時も上部に固定）
- 背景に `backdrop-filter: blur()` を適用して半透明に
- セクションリンクをクリックでスムーススクロール
- 言語切替ボタン（`EN` / `JA`）

## i18n 設計

- `react-i18next` を使用
- 翻訳ファイルは `src/i18n/ja.json` と `src/i18n/en.json`（i18n 設定と同ディレクトリに配置）
- フォールバック言語: 日本語
- **言語判定の優先順位**: localStorage（過去の選択）→ `navigator.language`（ブラウザ設定）→ 日本語（フォールバック）
- ヘッダーのボタンで手動切替可能
- 切替時に `localStorage` に保存

## Footer

- シンプルなコピーライト表示（`© 2026 名前`）
- 「Built with React + Vite」等のテキストは任意

## デプロイ

- Cloudflare Pages に静的サイトとしてデプロイ
- ビルドコマンド: `vp build`
- 出力ディレクトリ: `dist`
- GitHub リポジトリと連携し、`main` ブランチへのプッシュで自動デプロイ
