# 仕事に求めるもの

## 環境

- **少人数 / スタートアップ**: 裁量が大きく、幅広く関われる環境
- **自社プロダクト**: 一つのプロダクトを長期的に育てたい
- **リモート / 柔軟な働き方**: 場所や時間に縛られない働き方
- **シニアエンジニアの存在**: 技術的なメンターやロールモデルがいる環境で成長したい
- **高い技術基準**: コード品質や設計に対する高い基準がある組織

## 個人開発と企業の両輪

個人でできることはこれからもどんどんやっていく。YouTube 自動運用システム、npm パッケージ、dotfiles のような個人プロジェクトは技術的な探求の場として継続する。一方で、企業でしかできないスケールのプロダクト（大規模データ、チーム開発、社会インフラ）にも興味がある。
