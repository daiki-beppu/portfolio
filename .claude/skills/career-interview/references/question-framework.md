# 想定質問フレームワーク

## 質問カテゴリ

応募先企業の分析ファイルと career Knowledge から、以下のカテゴリで想定質問を生成する。
固定の質問リストではなく、企業ごとに最も聞かれそうな質問を導出する。

### 1. 経歴系

career-history.md と transfer-reason.md から導出。
面接官が「この人のストーリーを理解したい」と思う質問。

- 経歴の転換点に関する質問
- 転職動機に関する質問
- 現職での役割・成果に関する質問

### 2. 技術系

skills-inventory.md と career-history.md から導出。
面接官が「この人の技術力を測りたい」と思う質問。

- 技術選定の意思決定プロセス
- 設計判断とそのトレードオフ
- 失敗経験とそこからの学び

### 3. カルチャーフィット系

企業分析ファイルのバリュー・文化から導出。
面接官が「うちのチームに合うか」を判断する質問。

- 企業のバリューに関連するエピソード
- チームでの働き方に関する質問
- 企業固有の懸念を突く質問（経験年数、ドメイン知識など）

### 4. 志望動機系

transfer-reason.md と企業分析ファイルから導出。
「なぜうちなのか」への説得力ある回答。

- 転職軸と企業の接点を具体的に語る
- 他社ではなくこの企業である理由

## 回答のフレームワーク

回答は STAR 法（Situation → Task → Action → Result）をベースに構成する。
ただし機械的に当てはめるのではなく、質問の意図に応じて柔軟に調整する。
