# 逆質問設計フレームワーク

## 原則

逆質問は「情報収集」と「自分を印象づける」の2つの目的を同時に果たす。
企業分析ファイルの「懸念点・確認したいこと」を質問に変換するのが最も効果的。

## 質問カテゴリ

### 1. 成長環境を確認する質問

転職軸の「FB 文化・成長環境」に対応。
具体的な仕組み（レビュー頻度、1on1、メンタリング）を聞く。

### 2. チームの実態を確認する質問

求人票には載らない日常を聞く。
開発フロー、ペアプロの頻度、技術的な意思決定プロセスなど。

### 3. 自分の貢献可能性を示す質問

質問の形で自分のスキルをアピールする。
「御社では〇〇のような取り組みはされていますか？前職ではこういう成果がありまして...」

### 4. カルチャーを確認する質問

バリューの実践事例を具体的に聞く。
「〇〇というバリューが印象的だったのですが、最近それを体現したエピソードはありますか？」

## 避けるべき質問

- 求人票や公開情報に書いてあること
- 待遇・条件に偏りすぎる質問（初回面接では特に）
- Yes/No で終わる質問（会話が広がらない）
