# 企業比較マトリクス

## 比較観点の導出

観点をハードコードしない。以下の Knowledge から動的に抽出する:

1. `career/transfer-reason.md` → 転職で解決したい課題（＝重み x3 の候補）
2. `career/work-preferences.md` → 仕事に求める条件（＝重み x2 の候補）
3. `career/future-goals.md` → 長期的な方向性（＝重み x1 の候補）

### 抽出手順

1. 上記3ファイルを読み、ユーザーが重視している観点を箇条書きで列挙する
2. 類似する観点はマージして5〜8項目に絞る
3. 重みを設定する:
   - x3: 転職理由に直結する観点（これがなければ転職する意味がない）
   - x2: 強く求めている条件（あると嬉しい、ないと不満）
   - x1: 方向性との整合（長期的には重要だが今すぐの判断材料ではない）
4. ユーザーに「この観点と重みで合っていますか？」と確認する

## ギャップ分析

スコアリング後に確認する:

- **スコアが高い方**と**直感で選びたい方**は一致しているか？
- 一致しない場合、そのギャップが示すものは何か？
  - 言語化できていない判断基準があるかもしれない
  - 無意識の重み付け（ブランド、周囲の評価など）かもしれない
- ギャップの正体を特定したら、それを新しい観点として追加するか検討する

## 判断の問い

数字で割り切れないときに使う:

1. 5年後、どちらの経験を語りたいか？
2. 日曜夜、どちらの月曜を楽しみに思えるか？
3. 尊敬するエンジニアはどちらにいそうか？
4. 入社半年後の自分は、何をしているか具体的に想像できるか？
