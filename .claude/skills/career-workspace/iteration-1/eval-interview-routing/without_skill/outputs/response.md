# SmartHR 面接準備ガイド

## 1. 企業研究

- **事業内容**: SmartHR はクラウド人事労務ソフトを提供する SaaS 企業。入社手続き・年末調整・雇用契約などの労務管理をペーパーレス化するプロダクトが主力
- **ミッション**: 「well-working 労働にまつわる社会課題をなくし、誰もがその人らしく働ける社会をつくる。」
- **プロダクト**: 人事労務の基本機能に加え、タレントマネジメント機能（従業員サーベイ、人事評価、配置シミュレーションなど）を拡充中
- **技術スタック**: Ruby on Rails、React/TypeScript が中心。デザインシステムとして SmartHR UI（OSSとして公開）を運用
- **組織文化**: オープンな情報共有を重視し、社内ドキュメントの大部分を公開。「早いほうがカッコイイ」などの行動指針がある
- **最近の動向**: マルチプロダクト戦略を推進しており、新規プロダクトの立ち上げが活発

## 2. 想定される質問と準備

### 自己紹介・経歴

- これまでの経験を 2〜3 分で簡潔に話せるようにする
- 技術的な成長ストーリーを意識する

### 技術的な質問

- 使用技術（React, TypeScript など）の基礎的な理解
- 設計判断の理由を説明できるようにする（「なぜその技術を選んだか」）
- コードレビューやチーム開発の経験

### 行動面接（STAR メソッドで準備）

- 困難な技術課題をどう解決したか
- チームでの意見の衝突をどう乗り越えたか
- 失敗から何を学んだか

### SmartHR 固有の質問

- なぜ SmartHR を選んだのか（他の SaaS 企業ではなく）
- SmartHR のプロダクトや文化のどこに共感するか
- 人事労務ドメインへの関心

## 3. 逆質問の準備（3〜5 個用意）

例:

- チームの開発プロセス（スクラム等）について
- 新規プロダクト立ち上げのエンジニアリング体制
- 技術的負債への向き合い方
- オンボーディングの流れ
- デザインシステム（SmartHR UI）の運用体制

## 4. その他の準備

- **ポートフォリオの整理**: 自分のポートフォリオサイトやGitHub を見直し、説明できるようにする
- **SmartHR のテックブログを読む**: 技術的な取り組みや文化を理解するのに役立つ
- **SmartHR UI（OSS）を触ってみる**: プロダクトへの関心を示せる
- **服装**: カジュアルな企業文化なので、清潔感のあるカジュアルで問題ない（念のため募集要項やメールを確認）
- **面接形式の確認**: オンラインか対面か、所要時間、面接官の人数などを事前に確認
