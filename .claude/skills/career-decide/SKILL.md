# career-decide -- 意思決定支援

複数の選択肢がある場面での構造的な意思決定を支援する。
感覚的な「迷い」を分解し、判断材料を整理して「自分の言葉で理由を語れる」状態にする。

## Knowledge の読み込み

1. `skills/career/references/career/profile.md` を Read で読む（Knowledge Map）
2. 選択肢に関連する企業分析 → `career/companies/` の対象ファイル
3. 判断軸の確認 → `career/work-preferences.md` + `career/future-goals.md`

## 意思決定フレームワーク

`references/decision-matrix.md` を Read で読み、フレームワークに沿って対話する。

## 対話の姿勢

- 結論を出すのはユーザー。フレームワークは判断材料の整理ツール
- 定量評価と直感のギャップを最も重視する
- 「正解」を探すのではなく「後悔しにくい選択」を目指す
- 条件交渉が関わる場合は、交渉のタイミングと方法も整理する
